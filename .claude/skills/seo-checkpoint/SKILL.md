# SEO Real URLs checkpoint

Do these steps in order. Do not skip a step.

1. **Read** `docs/seo-real-urls/STATUS.md` as it is now.
2. **Checklist:** tick every step that is fully complete. Do not tick a step that is partly done.
3. **Current position:** update the current phase, current step, "waiting on" and next action.
4. **Phase status:** if all steps of the phase are done, set the phase to `waiting for review`. Never set a phase to `approved` yourself. Only Rohith approves.
5. **Decision log:** add one dated line for each decision made since the last checkpoint (by Rohith, or agreed with them). Do not delete old lines.
6. **Open questions:** add new questions for Rohith. Remove answered questions and log the answer as a decision.
7. **Other docs:** if a decision changes the content of `00-context.md` or another phase doc, update that file too. Add a line to the "Document change log" for every file you changed.
8. **Last updated:** set the date and "by Claude Code".
9. **Report:** give Rohith a short summary:
   - what was completed
   - what changed in the docs
   - open questions
   - the next action
10. If the phase is now `waiting for review`, **stop** and wait for approval.
